# Tylode Calendar · Descargas

Instaladores de **Tylode Calendar**, el calendario de [Tylode](https://tylode.com) en su propia app: tu calendario personal y el de cada espacio, cada uno como una capa que enseñas u ocultas, y un aviso antes de cada evento. Es gratis en todos los planes y usa tu cuenta de Tylode.

**[Descargar la última versión para Windows](https://github.com/NchCid-TA/tylode-calendar-descargas/releases/latest)** — el archivo `Tylode-Calendar-Setup-….exe`.

- Se instala sin permisos de administrador, junto a Tylode si ya lo tienes, y se actualiza sola.
- Si Windows dice «Windows protegió su PC», pulsa **Más información → Ejecutar de todos modos**: la app todavía no lleva firma digital.
- También puedes usarlo en el navegador: [app.tylode.com/calendario](https://app.tylode.com/calendario).

Ayuda: support@tylode.com
